# Contributing to Impact Uplift

Thanks for wanting to help. This app is built by a high school class, so the way it changes is a little different from most projects.

## Ideas and bugs

Open an issue. Say what you saw, what you expected, and the steps to repeat it. Please do not add the `build` label: that label is reserved for the students' requests, and only maintainers can apply it.

## Code

Pull requests are welcome for fixes, accessibility and performance. Keep the app plain HTML, CSS and JavaScript, and keep the build stamp (`<script src="/build-stamp.js"></script>`) on every page. Do not change `.github/`, `CLAUDE.md`, `firebase.json`, `.firebaserc` or `build.json` without talking to a maintainer first. The students decide what features the app has, so a pull request that adds a feature may be turned into a request for them instead.

## Rules everyone follows

- No real information about the people the partners serve, and no real donations or payment links.
- First names only for students. No photos, emails or phone numbers.
- Be kind. The people reading and answering issues include high school students.
